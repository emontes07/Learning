Copilot Skills Everywhere

How the same reusable SKILL.md approach works across Cowork, Excel, PowerPoint, and SharePoint, with each experience using its own management and storage model.

Core idea: a skill is a reusable set of instructions for a repeatable task. The folder and SKILL.md structure is consistent, but availability, storage, sharing, and governance differ by experience.

What is a skill?

Save the workflow once, then invoke it by describing the task or naming the skill.

Reusable instructions

A skill captures steps, quality checks, output requirements, and guardrails so users do not need to recreate a complex prompt each time.

Standard structure

Each custom skill uses its own folder containing a file named exactly SKILL.md. The file includes a name, description, and the instructions.

Context-specific execution

Excel skills can guide workbook tasks, PowerPoint skills presentation tasks, Cowork skills broader Microsoft 365 workflows, and SharePoint skills site workflows.

Cowork

Best for personal or shared repeatable workflows that can span Microsoft 365 work.

Generally available
  1. Open Cowork and select Customize, then the Skills tab.
  2. Select Add → Create new for the guided builder, or choose Upload skill to import an existing skill.
  3. You can also ask Cowork in chat to create a skill, or create the folder and file directly in OneDrive.
  4. Test changes in a new conversation. Enable, disable, edit, download, share, or delete personal skills from their detail pages.

Verified storage path

Documents/Cowork/skills/<skill-folder>/SKILL.md

Published limits

Up to 50 custom skills. A single Markdown upload can be up to 1 MB. Skill archives can be up to 10 MB compressed, 50 MB uncompressed, and 100 files.

Sharing

A creator can keep a skill private or share it with specific people in the organization. Re-share after changes to distribute the latest version.

Trust boundary

A skill is instruction content for the AI. Microsoft advises users to upload skills only from trusted sources.

Create a skill that prepares my weekly status update from recent email, Teams, and calendar activity.

Copilot in Excel

Best for repeatable workbook tasks, including analysis, tables, formulas, charts, cleanup, and formatting.

Custom Office.js skills are preview
  1. Open Copilot in Excel. In the prompt field, select Add work content → All Skills.
  2. To manage skills, select Settings (…) → Manage skills.
  3. Under Custom skills, select Create OneDrive folder, then Open skills folder.
  4. Add one folder per skill. Each folder must contain SKILL.md and its folder name must match the skill name. Select Refresh after adding or renaming a skill.
  5. Invoke a skill from All Skills or type an @mention such as @data-analysis.

Storage

Microsoft's current support article confirms that Excel creates a dedicated Skills folder in the user's OneDrive, but the article does not publish the exact folder path. Use Create OneDrive folder in the Excel Copilot pane and verify the resulting location in your tenant.

Workbook output

Design most Excel skills to put the result in the workbook, not only in chat.

Office.js option

A skill can include scripts that call Office.js. Copilot initializes the runtime, so scripts should not call Office.onReady or define Office.initialize.

Limits

The current Excel support page does not state a custom-skill count or upload-size limit. Verify current limits in your tenant before a managed rollout.

Preview warning: Microsoft states that custom skills for Excel using Office.js are in preview and should not be used as production skills.

Copilot in PowerPoint

Best for reusable presentation workflows such as copyediting, executive summaries, slide creation, and design consistency.

  1. Open Copilot in PowerPoint. Select the + menu in the prompt field, then Choose skills.
  2. Scroll to Manage skills, then select Add skill to upload or drag and drop a skill. You can also paste a skill into the Add skill form.
  3. Alternatively, select Settings (…) → Manage skills → Custom skills → Create OneDrive folder, then open the folder and add skill folders directly.
  4. Invoke a skill from Choose skills or type an @mention such as @copyedit-this-presentation.
  5. Edit or delete personal skills in the Manage skills pane. Refresh after changing files directly in OneDrive.

Storage

Microsoft confirms that uploaded PowerPoint skills are stored in the user's OneDrive Skills folder. The current support article does not publish the exact path, so use the app's folder-creation flow and verify the resulting location in your tenant.

Personal use

The PowerPoint support article describes uploaded custom skills as personal to the user.

Selection behavior

Disabled skills are not used automatically and do not appear in the skill dropdown until re-enabled.

Limits

The current PowerPoint support article does not state a skill count or upload-size limit. Verify current limits in your tenant.

Copilot in SharePoint

Best for reusable workflows that should be available to people working on the same SharePoint site.

Preview
  1. Open the Copilot in SharePoint chat panel from a site page or document library. The page must not be in edit mode.
  2. Describe the repeatable workflow and ask Copilot to create a skill.
  3. Review the proposed steps, inputs, and outputs, then confirm that the skill should be saved.
  4. Run it by making a matching request or explicitly say, “Run [skill name] on the selected documents.”
  5. Look for the skill indicator in chat to confirm that the skill loaded.

Verified storage path

/Agent Assets/Skills/<skill-name>/SKILL.md

Permissions

By default, users with Edit permission can create skills; users with View permission can run them.

Governance

Apply standard SharePoint controls to the Agent Assets library, including permissions, retention, sensitivity labels, and auditing.

Capability boundary

SharePoint skills cannot connect to external systems or run custom code. They use capabilities and permissions already available to the user on the site.

Create a skill that reviews selected documents for missing required metadata and records the gaps in a SharePoint list.
